起笔 · 小说创作与阅读平台
============================

一、项目简介
------------
起笔是一个面向多作者的中文小说创作与阅读平台，包含：

- 书库、作品管理与公开阅读
- 章节树、Markdown 正文编辑器与自动保存
- 总纲与每章独立细纲
- 章节历史版本快照、一键撤回与版本管理抽屉
- CodeMirror 选区右键快捷菜单：AI 润色选区、AI 扩写选区、复制、剪切
- 人物库、人物关系网络、AI 正文提取角色与交互式审核导入
- 世界地图编辑器：多图层流畅渲染、区域/地标/路径/人物标点与 AI 正文完善地图
- 三路独立 API 配置架构：小说写作助手、角色与地图设定库及蒸馏作者独立配置 API Key / Base URL / 协议 / 模型（角色与地图共用同一配置）
- 小说写作助手：作者 Skill、进度记录、伏笔检查、章末钩子、节奏检查、角色档案、总纲规划、素材搜索关键词和配图 Prompt
- 蒸馏作者：导入 TXT/EPUB 等授权材料，生成 writing skill、author persona 和完整 Skill，支持版本查看、追加进化与回滚
- 多作者账号隔离、登录认证与管理员功能

二、本地启动与打包
------------------

项目目录：
C:\Users\Administrator\Desktop\xm\XXS

首次安装依赖：
    npm install

开发模式需要打开两个终端：

终端一（后端 API）：
    cd /d C:\Users\Administrator\Desktop\xm\XXS
    npm run dev:server

后端地址：
    http://localhost:3000
健康检查：
    http://localhost:3000/api/health

终端二（前端）：
    cd /d C:\Users\Administrator\Desktop\xm\XXS
    npm run dev:web

前端地址：
    http://localhost:5173

生产打包为 Windows 便携版 EXE：
    1. 打包本地单机写作版客户端 EXE：
       npm run build:exe
       生成：desktop/release/起笔-1.0.0-portable.exe

    2. 打包公网服务器图形化一体版 EXE（直接接入公网）：
       npm run build:server-exe
       生成：desktop/release/起笔-公网服务器-1.0.0-portable.exe

       ★ 【起笔-公网服务器.exe】特性：
       - 双击直接启动本地全能服务（0.0.0.0 监听）并自动集成 Cloudflare 全球公网隧道。
       - 图形化控制台窗口实时展示分配的全球公网访问网址（如 https://xxx.trycloudflare.com），带一键复制与在浏览器中打开。
       - 自动识别并展示局域网内同一 WiFi 下的手机/平板直连 IP。
       - 100% 本地数据库存储，所有账号与作品数据留在当前电脑。
       - 彻底摆脱命令行黑框，支持一键重启隧道与一键打开本地写作台。

如果 5173 或 3000 已被旧进程占用，请先关闭对应的 Node/Vite 进程，再重新启动。

三、AI 配置（三路独立配置架构）
----------------------------

AI 设置入口：登录后进入“设置”。系统已将【小说写作助手】、【角色与地图】与【蒸馏作者】的 API 配置完全拆分为独立模块，允许针对不同场景与任务独立配置不同的服务商、网关、协议和模型：

1. 小说写作助手 · API 配置
- 用途：章节草稿生成、续写、全文/选区润色、扩写、细纲规划与写作顾问等高频创作任务。
- 支持独立配置 API Key、实际 API Base URL、协议（Anthropic 原生 / OpenAI 兼容）以及模型名称。
- 支持一键点击“连接本地 CC-Switch”填入本机代理地址。
- 支持“持久保存（加密落库）”与“仅本次会话（更私密）”。

2. 角色与地图 · 专用 API 配置（正文角色提取与地图完善共用）
- 用途：【人物库 · AI 提取正文角色】与【地图编辑器 · AI 完善地图要素】两者共用此处的专属 API 配置。
- 特性：如果未单独填写此项，系统将自动优雅回退并共用【小说写作助手】的 API 配置，避免重复填写。
- 优势：当用户希望针对角色关系挖掘或地理要素测绘使用专门的分析大模型（如高推理能力模型）时，可在此单独指定专用的 Key、Base URL、协议和模型。
- 支持独立一键“连接本地 CC-Switch”与持久/会话模式。

3. 蒸馏作者 · 专用 API 配置
- 用途：长篇小说大文本样本深度剖析、提取写作能力 (writing skill)、提取作者人格 (author persona) 及合并风格 Skill。
- 建议配置支持超长上下文（如 1M 上下文）的模型服务。
- 同样支持独立的 API Key、Base URL、协议与模型，与前述两项互不干扰。
- 支持独立一键“连接本地 CC-Switch”与持久/会话模式。

4. 配置参数说明
- API Key / 令牌：填写对应上游或网关的 API 密钥。
- 实际 API Base URL：必须是提供接口的实际服务地址（如 https://api.anthropic.com 或 http://127.0.0.1:15721/v1）。请勿填写 https://ccswitch.io/ 官网。
- 协议与模型：
  * Anthropic 原生：调用 /v1/messages 接口。
  * OpenAI 兼容：调用 /chat/completions 接口。
  * 模型填写对应供应商的具体模型标识符（如 claude-opus-5、deepseek/deepseek-v4-flash 等）。

4. 站方配置回退与安全：
- 若用户未填写个人配置，且站方配置了环境变量（ANTHROPIC_API_KEY），系统会自动回退使用站方配置。
- 个人 Key 加密落库，绝不在前端明文回显，保障账户安全。

安全提醒：不要把 API Key、SESSION_SECRET、Cookie 或其他凭据写进说明文档、截图、日志或提交到公开仓库。

四、章节正文版本历史与选区右键操作
----------------------------------

1. 自动快照与历史版本抽屉
- 当 AI 生成正文（按细纲写章、续写、全文润色、扩写）或用户执行版本恢复时，系统会自动将修改前的正文备份至数据库 `chapter_revisions`。
- AI 生成完成后，编辑器顶栏会浮现快捷提示条：可直接点击【一键撤回上个版本】快速撤销。
- 点击顶部工具栏的【历史版本】按钮，即可滑出版本历史抽屉：
  * 左侧时间轴清晰列出每个快照的备份原因、生成时间、字数。
  * 右侧支持实时对比查看该版本的完整正文。
  * 点击【恢复此版本】，即可一键还原正文（同时会将当前正文再做一次快照，防止误操作）。

2. 选中文字右键快捷菜单（选区润色与选区扩写）
- 在编辑器中用鼠标选中任意一段文字，直接【鼠标右键】即可唤起暗色悬浮菜单：
  * ✨ **AI 润色选区**：直接提取所选段落发往 AI 进行行文修饰与表达升级，流式展示预览后可点击【应用替换】。
  * 📝 **AI 扩写选区**：针对选中段落进行细节、心理活动、环境与动作描写扩充，丰富段落层次。
  * ✂️ **复制选区 / 剪切选区**：快捷复制或剪切到剪贴板。

五、角色库：AI 正文提取与审核确认
--------------------------------

1. AI 自动提取角色
- 进入小说【人物库】页面，点击顶部【✨ AI 正文提取人物】按钮。
- 可选择分析范围：【全部已有章节】或【最近章节】。
- 点击【开始提取人物】，AI 将深度分析小说正文，提取所有出场或提及的人物设定（姓名、称号/别名、角色定位、性别、年龄、性格、容貌外貌、背景经历、人物关系）。

2. 交互式审核与批量导入
- 提取完成后弹出审核面板，系统会自动与已有角色比对，标注【新人物】或【已有同名（合并完善）】。
- 支持在审核列表中直接修改姓名、角色类型、性格、外貌、背景等各项属性。
- 支持全选 / 全不选 / 单独勾选需要采纳的人物。
- 点击底部【确认导入 (X 个人物)】，即可一键批量存入数据库，人物卡片即时刷新呈现。

六、地图编辑器：流畅度优化与 AI 完善地图
----------------------------------------

1. Konva 画布渲染流畅度深度优化
- 背景与网格线迁移至独立离屏图层（`listening={false}` 与 `perfectDrawEnabled={false}`），平移缩放时不再参与复杂事件命中检测与重绘，彻底解决卡顿问题。
- 图形、路径、文字标注与人物标点均关闭多余离屏合成，大幅降低 GPU/CPU 开销。
- 滚轮缩放与鼠标抓手平移丝滑达到 60fps。

2. AI 根据小说正文自动完善地图要素
- 在地图编辑器顶栏点击【✨ AI 完善地图】按钮。
- 点击【开始提取地理要素】，AI 将通读小说正文，提取其中提到的势力疆土/宗门区域 (Shapes)、名城险关/地标据点 (Labels)、交通商道/山川江河 (Paths)，并根据 1600x1000 画布空间分配合理坐标与颜色。
- 审核面板分类展示提取到的地理要素，支持单选/复选与颜色预览。
- 点击【合并应用到当前地图】，选中的地理元素将平滑合并进当前地图并自动持久化。

七、常见问题与排查
------------------

1. 页面打开后只显示背景色
先确认后端和前端都已启动，并访问：
    http://localhost:3000/api/health
如果返回 {"ok":true}，再刷新前端页面。

2. AI 返回 401/403
通常是 API Key 无效、已过期、权限不足，或代理要求的令牌格式与服务协议不匹配。重新检查“API Key / 令牌”和协议选择。

3. AI 返回 404
通常是 Base URL 填错，或者把官网地址当成了接口地址。不要填写 https://ccswitch.io/；请填写实际 API endpoint（如 http://127.0.0.1:15721/v1），并确认 /v1 与协议配置正确。

4. AI 返回 429
表示上游服务或站方每日限额触发了限流。稍后重试，或更换有可用额度的账号/网关。

5. 选区右键菜单没有弹出
请确认已用鼠标选中文本（光标有选中高亮区域）；未选中文本时右键会保留浏览器原生右键菜单。

6. 地图画布平移
切换到顶部工具栏的【平移/缩放】（手掌图标）工具后，即可在画布任意空白处按住鼠标左键自由拖拽平移，滚轮上下滑动可缩放视图。

八、部署与维护提示
------------------

- 生产环境请使用随机且足够长的 SESSION_SECRET。
- 数据库位于 server/data/，升级前请备份 novelforge.db。
- 不要提交 server/.env 到公开仓库。
- 不要在日志中打印 Authorization、x-api-key 或解密后的密钥。
- AI 请求由后端代理发出，浏览器不会直接获得服务端站方密钥。
- 更新依赖或代码后建议执行 npm run build 或 npm run build:exe 检查编译完整性。

九、公网/局域网服务器模式（本机作为主服务器，多端与外网协同）
--------------------------------------------------------

1. 架构理念与数据本地化保障
- **本机即主服务器**：无论通过局域网、内网穿透还是公网域名访问，服务端均直接运行在当前电脑上。
- **登录信息与数据 100% 本地存储**：
  * 所有作者账号、加密密码 Hash、登录会话均保存在本地 SQLite 数据库（`data/novelforge.db`）。
  * 数据库与上传材料绝不上云，完全掌握在作者自己的电脑上，保障隐私与版权安全。
- **全网监听 (0.0.0.0)**：服务端默认监听 `0.0.0.0:3000`，自动支持本机、同一局域网设备以及公网穿透访问。

2. 一键启动方式（Windows）
- 在项目根目录下，直接双击运行：
  `启动服务器(公网与局域网模式).bat`
- 脚本会自动检查环境并完成前后端编译，并在命令行中清晰打印：
  * 本机电脑访问地址：`http://localhost:3000`
  * 局域网/手机访问地址：`http://192.168.x.x:3000`（根据当前电脑连接的 WiFi/路由器 IP 动态显示）
  * 数据库文件物理存储路径

3. 局域网多设备协同（手机 / 平板 / 笔记本）
- **前提条件**：手机、平板或另一台笔记本与主机连接在同一个 WiFi 路由器或同一局域网下。
- **访问方式**：
  1. 在主机上打开本软件或运行服务端；
  2. 进入「设置」页面，在顶部的【本机服务器与网络模式】卡片中，即可看到「📱 手机 / 平板 / 局域网访问」地址（例如 `http://192.168.1.100:3000`）；
  3. 点击复制，或者在手机浏览器中直接输入该网址，即可打开完整的创作与阅读工作台；
  4. 支持在手机或平板上登录作者账号，实时同步创作进度与草稿。

4. 公网与远程异地访问方案（在公司、咖啡厅或户外访问家里电脑）
- **方案 A（推荐，极简快速）：内网穿透（cpolar / Cloudflare Tunnel / frp）**
  * 使用 [cpolar](https://www.cpolar.com/) 或 [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)，将本地端口 `3000` 映射为安全的公网 HTTPS 域名；
  * 外部任何设备通过该公网域名即可直接打开起笔工作台，登录信息仍由本机 SQLite 数据库严格鉴权。
- **方案 B：路由器端口映射 (NAT 转发)**
  * 如果宽带拥有公网 IPv4 或 IPv6，在家里路由器后台添加“虚拟服务器 / 端口转发”，将外部端口转发至主机的 `3000` 端口；
  * 结合 DDNS 动态域名，随时随地通过固定域名访问本机。
- **方案 C：虚拟局域网（Tailscale / ZeroTier）**
  * 主机和手机均安装 [Tailscale](https://tailscale.com/)，在手机浏览器中输入主机的 Tailscale IP（如 `http://100.x.x.x:3000`）即可实现点对点加密直连。
