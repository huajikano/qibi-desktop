第一步：配置你的专属 AI 创作接口（三路独立配置详解）
================================================================================

【为什么必须配置个人 API？】
为了保障每位作者的创作自由与隐私，并避免公共接口额度拥挤，平台采用「用户专属 Key」加密隔离机制。
你保存的 API Key 在后台会经过 AES-256-GCM 强加密存储，只有在为你生成内容时解密，其他人无法查看。

【进入配置页面】：
1. 注册并登录你的作者账号；
2. 点击顶部导航栏的「⚙️ 设置」，进入「AI 模型与接口配置」面板。

系统已贴心地将 API 拆分为三路独立架构，满足不同任务的高性能需求：

1. 【小说写作助手 · API 配置】（高频创作必备）
   - 用途：章节草稿生成、正文续写、全文润色/扩写、细纲自动规划、伏笔检查、选区润色等。
   - 填写项：
     * API Key / 令牌：填入你的大模型服务商密钥（如 Anthropic、OpenAI、DeepSeek、SiliconFlow 等提供的 Key）。
     * 实际 API Base URL：大模型接口的网关地址（如 https://api.deepseek.com/v1、https://api.openai.com/v1 等）。
     * 接口协议：
       - Anthropic 原生：调用 /v1/messages 接口；
       - OpenAI 兼容：调用 /chat/completions 接口（推荐，兼容 DeepSeek、OneAPI、NewAPI 等绝大部分服务商）。
     * 模型名称：填入具体的模型代号（如 deepseek-chat、claude-3-5-sonnet、gpt-4o 等）。
   - 保存选项：选择「持久保存（加密落库）」后点击「保存助手配置」。

2. 【角色与地图 · 专用 API 配置】（可选，提取分析专用）
   - 用途：【人物库 · AI 提取正文角色】与【地图编辑器 · AI 完善地图要素】共用此处的专属 API。
   - 智能回退：如果你未单独填写此项，系统将自动回退共用上述【小说写作助手】的配置，免去重复填写的繁琐。
   - 如果你想使用高推理能力或特定模型提取复杂人物关系和地理要素，可在此处单独指定专属 Key 与模型。

3. 【蒸馏作者 · 专用 API 配置】（大文本样本剖析）
   - 用途：导入数万至百万字的长篇小说原著材料，深度剖析作者的写作技巧 (writing skill) 和人格特色 (persona)。
   - 建议：推荐配置支持超长上下文（如 128k ~ 1M 上下文）的模型服务。

第二步：创建作品与作品可见性（公开 vs 私密）
================================================================================

1. 新建作品：
   - 进入「我的书架」，点击右上角「➕ 新建作品」；
   - 填写书名、类型（玄幻/都市/科幻等）、简介。

2. 作品可见性设置（公开 / 私密）：
   - 🌐 【公开作品】：展示在首页公开书库与读者端，所有读者可浏览你的作品简介、大纲和已发布章节。
   - 🔒 【私密作品】：从公开书库彻底隐藏，仅你本人（及管理员）登录后可见，适合创作初期大纲草拟或个人私密作品。
   - 快捷切换：在「我的书架」作品卡片上，或在「写作台」顶栏，均可一键点击「公开 / 私密」徽章随时切换状态。

第三步：章节正文创作、自动保存与移动端/手机使用技巧
================================================================================

1. 写作台三栏布局（桌面端）：
   - 左侧：作品总纲（大纲总览、主线剧情）；
   - 中间：Markdown 正文编辑器（支持每 1.5 秒自动静默保存、字数实时统计、发布/草稿状态切换）；
   - 右侧：章节树（点击切换章节、上移/下移、新建章节）与每章独立的「本章细纲」。

2. 📝 中文小说标准排版与首行缩进两个字符：
   - 【编辑器与阅读器自动缩进】：正文编辑器（CodeMirror）与读者端均已原生适配中文小说段落规范，每段文字开头自动首行缩进 2 个字符（2em），长段落自动折行对齐，沉浸感媲美出版物；
   - 【🧹 一键缩进排版】：在章节标题栏右侧设有「一键排版」按钮，无论从外部粘贴杂乱文本还是自敲草稿，点击即可秒级将整章所有自然段规范化为标准首行空两格（　　）；
   - 【AI 生成全自动规范】：AI 创作正文、续写、润色与扩写时，均已严格遵守首行缩进 2 字符排版标准。

3. 📱 手机与移动端流畅码字（响应式自适应设计）：
   - 在手机浏览器上访问时，系统自动切换为移动端 Tab 模式：
     * 【✍️ 正文写作】：全屏独占编辑器，字号与触控优化，彻底告别侧边栏挤压；
     * 【📑 章节细纲】：全宽浏览章节列表与细纲，点击任意章节即可无缝秒切回正文继续码字；
     * 【📜 作品总纲】：全宽查看与编辑主线总纲。

第四步：AI 辅助创作、选区右键快捷菜单与正文外观定制
================================================================================

1. AI 写作助手抽屉：
   - 在写作台顶栏点击「✨ AI 助手」唤起抽屉；
   - 支持按细纲生成正文、剧情续写、全文润色、全文扩写、本章总结、细纲建议等；
   - 进度记录与伏笔清单：随手记录当前卷进度、待埋/待回收伏笔。

2. ✨ 选区文字右键快捷菜单（重点推荐）：
   - 在编辑器中用鼠标（或手机端长按）选中任意一段文字；
   - 点击【鼠标右键】，直接唤起暗黑悬浮操作菜单：
     * ✨ **AI 润色选区**：针对选中的文字进行精修、文笔提升和修辞优化，流式预览满意后点击【应用替换】；
     * 📝 **AI 扩写选区**：对选中的段落补充环境描写、心理活动、神态对话，丰富篇幅层次；
     * ✂️ **复制选区 / 剪切选区**：快捷复制或剪切。

3. 🎨 正文编辑器外观自由定制：
   - 在「AI 助手」抽屉顶部，支持自由挑选编辑器「背景颜色」与「文字颜色」；
   - 偏好自动保存在你的本地浏览器中，随时随地享受护眼绿色、暗黑极简或羊皮纸质感。

第五步：章节历史版本快照与一键撤回机制
================================================================================

1. 自动快照机制：
   - 每次触发 AI 写章、续写、全文润色、扩写或手动版本还原前，系统会自动对修改前的正文进行全量快照。
   - AI 生成完毕后，顶部会弹出快捷提示条，点击【一键撤回上个版本】即可瞬间恢复。

2. 历史版本管理抽屉：
   - 点击顶栏「🕒 历史版本」按钮，滑出版本历史抽屉；
   - 左侧时间轴清晰标注每一次修改的原因、备份时间、字数变动；
   - 点击任意历史快照即可在右侧对比预览，点击【恢复此版本】一键回滚。

第六步：人物库管理与 AI 正文提取角色
================================================================================

1. 手动与可视化人物管理：
   - 进入小说「人物库」，支持为每个角色设定称号、角色定位（主角/配角/反派）、性格特征、容貌外貌、生平背景及多人物关系网。

2. ✨ AI 根据正文自动提取角色（全自动省心）：
   - 点击顶部「✨ AI 正文提取人物」，选择分析范围（全部章节 / 最近章节）；
   - AI 将自动通读正文，挖掘所有登场人物与其身份、性格、背景；
   - 在弹出的交互式审核列表中，支持逐一修改确认，勾选后点击【确认导入】，一键批量存入人物库。

================================================================================
第七步：世界地图编辑器与 AI 正文完善地图
================================================================================

1. 丝滑 60fps 地图绘制：
   - 支持多图层渲染、鼠标滚轮缩放、抓手拖拽平移；
   - 支持绘制势力领地区域 (Polygon)、名城关隘地标 (Labels)、山川交通路径 (Paths) 以及将人物标点直接放置在地图据点上。

2. ✨ AI 扫描正文完善地图要素：
   - 点击顶栏「✨ AI 完善地图」；
   - AI 自动提炼小说正文中出现的国家宗门疆界、城镇关隘与行军路线，生成合理的坐标分布供你审核合并。

第八步：蒸馏作者与长篇小说写作助手
================================================================================

1. 导入小说原著样本：
   - 支持 TXT、EPUB、Markdown 等格式材料上传；
2. 蒸馏生成专属 Skill：
   - AI 深度提取原著的修辞节奏、行文习惯、句式特征，提炼为专属风格 Skill；
3. 写作联动：
   - 在写作台「AI 助手」中选择蒸馏好的作者风格，AI 创作正文时将全自动代入该作者的行文神韵。

第九步：常见问题与排查指南
================================================================================

Q1: 点击 AI 生成时提示「未配置 AI 服务供应商」或「API Key 无效」？
A1: 请进入「⚙️ 设置」页面，检查【小说写作助手】中的 API Key、Base URL 是否填写完整并点击了保存。

Q2: 手机上写作时如何换章？
A2: 点击顶部 Tab 栏中的【📑 章节细纲】，点击想写的章节，系统会自动切换回【✍️ 正文写作】全屏编辑器。

Q3: 为什么别人看不到我刚建的书？
A3: 请检查作品是否设为了「私密」状态。在书架或写作台顶栏点击「私密」切换为「公开」即可全站展示。
